# 需求分析文档 - Chrome MCP Server 增强功能

**项目名称**: Chrome MCP Server - OpenAI 协议支持 & Claude 本地通信增强
**分析日期**: 2026-04-12
**文档版本**: v1.0

---

## 1. 需求概述

### 1.1 需求背景

当前 Chrome MCP Server 项目存在两个主要痛点：

1. **大模型接入受限**：仅支持通过 Claude Code CLI 和 Codex CLI 间接调用模型，无法直接配置 OpenAI 兼容 API
2. **前端调试复杂**：Sidepanel 前端页面调试需要通过完整的 MCP 认证流程，开发效率低

### 1.2 用户场景

#### 场景 1：使用第三方大模型服务

```
作为开发者
我希望在浏览器插件中直接配置 OpenAI 兼容的 API 端点
这样我可以使用 Azure OpenAI、本地部署的模型或其他第三方服务
而无需安装额外的 CLI 工具
```

#### 场景 2：前端页面快速调试

```
作为前端开发者
我希望本地 Claude 能够直接与插件通信
这样我可以快速调试 Sidepanel 前端页面
无需配置账号密码等复杂认证流程
```

## 3. 功能需求

### 3.1 需求 1：OpenAI 兼容协议配置

#### 3.1.1 功能描述

允许用户通过插件 UI 直接配置 OpenAI 兼容的 API 端点，配置项包括：

| 配置项       | 类型   | 必填 | 默认值 | 说明                       |
| ------------ | ------ | ---- | ------ | -------------------------- |
| API URL      | string | 是   | -      | OpenAI 兼容 API 的基础 URL |
| API Key      | string | 是   | -      | 认证密钥                   |
| Model        | string | 是   | gpt-4o | 模型名称                   |
| Organization | string | 否   | -      | 组织 ID (可选)             |
| Max Tokens   | number | 否   | 4096   | 最大生成 token 数          |
| Temperature  | number | 否   | 0.7    | 温度参数                   |

#### 3.1.2 支持的 API 端点

- [x] OpenAI 官方 API (https://api.openai.com/v1)
- [ ] Azure OpenAI Service
- [ ] 本地部署模型 (Ollama, vLLM, etc.)
- [ ] 第三方兼容服务 (DeepSeek, Moonshot, etc.)

#### 3.1.3 配置存储

- 配置存储位置：`chrome.storage.local`
- 加密要求：API Key 需要加密存储
- 同步要求：不支持跨设备同步（敏感数据）

### 3.2 需求 2：Claude 本地直连通信

#### 3.2.1 功能描述

启用本地调试模式后，本地运行的 Claude Code 可以直接与浏览器插件通信，无需经过完整的 MCP 认证流程。

#### 3.2.2 通信模式

```
┌─────────────────┐     HTTP/MCP      ┌─────────────────┐
│  Local Claude   │ ◄──────────────► │ Chrome Extension│
│  (CLI/Code)     │   免认证直连       │  (Native Server)│
└─────────────────┘                   └─────────────────┘
```

#### 3.2.3 安全考虑

| 风险         | 缓解措施                     |
| ------------ | ---------------------------- |
| 本地端口暴露 | 仅监听 localhost (127.0.0.1) |
| 未授权访问   | 调试模式需显式启用，默认关闭 |
| 敏感数据泄露 | 调试模式不存储任何认证信息   |

## 4. 非功能需求

### 4.1 性能要求

- API 配置加载时间 < 100ms
- 本地直连延迟 < 50ms
- 不影响现有 MCP 通信性能

### 4.2 安全要求

- API Key 加密存储（使用 chrome.storage API 内置加密）
- 本地调试模式默认关闭
- 调试模式启用时显示明确的安全提示

### 4.3 兼容性要求

- 兼容现有 MCP 协议客户端
- 兼容现有 Claude Engine 和 Codex Engine
- 向后兼容已有的配置格式

### 4.4 可用性要求

- 配置界面简洁直观
- 提供配置测试功能（一键验证 API 连通性）
- 错误提示清晰可操作
